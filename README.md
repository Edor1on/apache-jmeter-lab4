# Лабораторна робота № 4. Тестування продуктивності з використанням JMeter

Курс «Автоматизовані системи тестування програмного продукту», варіант 6.
Об’єкт тестування — сайт <https://github.com/>.

## Вміст репозиторію

| Файл або папка | Призначення |
| --- | --- |
| `GitHub_Performance_Test.jmx` | тест-план Apache JMeter |
| `results.jtl` | результати запуску: один рядок CSV на кожен запит |
| `report/` | HTML-звіт JMeter із таблицями й графіками (відкривати `report/index.html`) |

## Тест-план

Спільні елементи:

- **HTTP Request Defaults** — протокол `https`, сервер `github.com`;
- **HTTP Header Manager** — заголовки `User-Agent` і `Accept-Language`;
- **HTTP Cookie Manager** — зберігає cookies між запитами;
- **Response Assertion** — запит вважається успішним, лише якщо код відповіді 200;
- **Summary Report**, **Aggregate Report**, **View Results Tree** — перегляд результатів у графічному режимі.

Три групи потоків виконуються по черзі (параметр *Run Thread Groups consecutively*):

| Група | Користувачів | Ramp-up, с | Тривалість, с | Затримка старту, с |
| --- | --- | --- | --- | --- |
| `light (3 users)` | 3 | 5 | 30 | 0 |
| `medium (8 users)` | 8 | 5 | 30 | 30 |
| `high (15 users)` | 15 | 5 | 30 | 30 |

Кожен віртуальний користувач у циклі надсилає три запити GET:

| Запит | Шлях | Сторінка |
| --- | --- | --- |
| `home_page` | `/` | головна |
| `search` | `/search?q=dotnet` | результати пошуку |
| `repository` | `/dotnet/runtime` | сторінка репозиторію |

**Constant Timer** додає паузу 2 с перед кожним запитом.

## Запуск

Потрібні JDK та Apache JMeter 5.6.3. Тест запускається з командного рядка, у режимі без графічного інтерфейсу:

```
jmeter -n -t GitHub_Performance_Test.jmx -l results.jtl -f -e -o report -Jjmeter.reportgenerator.overall_granularity=5000
```

| Ключ | Значення |
| --- | --- |
| `-n` | режим без графічного інтерфейсу |
| `-t` | файл тест-плану |
| `-l` | файл, у який записуються результати |
| `-f` | видалити попередні результати і звіт |
| `-e -o` | після тесту згенерувати HTML-звіт у вказану папку |
| `-Jjmeter.reportgenerator.overall_granularity=5000` | крок графіків 5 с (типово 60 с) |

Тест триває близько 2,5 хв. Готовий HTML-звіт можна також побудувати з наявного файлу результатів:

```
jmeter -g results.jtl -o report -Jjmeter.reportgenerator.overall_granularity=5000
```
